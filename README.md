# C 项目脚手架

一个极简的 C 语言项目脚手架：**源码与编译产物分离**，配合 VS Code 的 Code Runner 一键编译运行。

## 快速开始
1. 将bat,ps1文件放到项目文件夹中
2. 双击 `新建C项目.bat`，输入项目名（建议英文），回车
3. 在生成的 `src\` 文件夹里新建 `xxx.c` 写代码
4. 用 VS Code 打开项目 → 打开 `src\` 里的 `.c` → 按 `Ctrl+Alt+N` 运行

exe 会自动编译进 `build\`，不污染源码目录。

## 目录结构

```
脚本所在文件夹\
├─ 新建C项目.bat      # 双击，一键创建新项目
├─ 新建C项目.ps1      # 脚本本体（自适应所在目录）
└─ README.md

   项目名\
   ├─ src\                      # 放 .c 源码
   ├─ build\                    # 放编译产物 .exe（自动生成，可删）
   └─ .vscode\settings.json     # 已配好 Code Runner
```

## 注意事项

- `.c` 源码**必须放进 `src\`**，否则编译找不到 `build`
- 脚本**自适应目录**：拷到任意文件夹都能用，无需改路径
- 前提：已安装 MinGW-w64（gcc）+ VS Code + Code Runner 插件
- 项目名建议用英文，避免中文路径兼容问题

## 常见问题

- **双击 `.bat` 闪退？** 右键 → 以管理员身份运行
- **报错 `'gcc' 不是内部或外部命令`？** 先装 MinGW-w64 并配置 PATH
